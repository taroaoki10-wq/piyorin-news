いますぐ更新の準備

このボタンは、GitHub Actions の「ぴよりんニュースを更新」を今すぐ実行します（1分ほどかかります）。実行にはあなた専用の合言葉が必要です。

  1. GitHubで合言葉を作る ↗ 開いた画面で「Repository access」を「Only select repositories」にして piyorin-news だけを選び、「Permissions」の Actions を「Read and write」にします。一番下の「Generate token」を押して、表示された github_pat_ で始まる文字をコピーします。
  2. 貼り付けて「保存して更新」を押します。

合言葉はこの端末のブラウザにだけ保存されます。更新のたびに Claude API が少し使われます。

ぴよと話す準備

ぴよの返事は Claude が考えます。使うには、あなたの Claude の API キーが必要です。

  1. Claude のコンソールで API キーを作る ↗ 「Create Key」を押して名前（例：ぴよりんニュース）を付け、表示された sk-ant- で始まる文字をコピーします。使いすぎが心配なら、コンソールで月の使用額の上限を決めておくと安心です。
  2. 貼り付けて「保存して話す」を押します。

API キーはこの端末のブラウザにだけ保存されます。1 回の質問で 1〜5 円ほどかかります（最初のまとめは無料）。解除は「ブックマーク」タブの下からできます。
